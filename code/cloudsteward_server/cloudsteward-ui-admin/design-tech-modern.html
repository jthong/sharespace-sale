设计说明 · Design Rationale

色彩策略

#FF6B35 品牌橙 · 仅用于 CTA 和激活态
#1D2129 标题色 · 正文用 #4E5969
#F2F3F5 背景 · 卡片纯白 #FFFFFF
#E5E6EB 边框 · 极度克制使用

橙色占比不超过界面 5%，大面积留白 + 灰阶层次营造高级感。参考 Linear、Vercel 的克制用色。

间距与圆角

基础间距单位 4px，组件内间距 8/12/16/20/24 递进。

卡片圆角 8px，按钮/输入框 6px，标签 4px。统一但不死板。

表格行高 48px，保证可读性和操作空间。

侧边栏菜单项高度 36px，紧凑但不拥挤。

阴影与层级

放弃重阴影，改用 1px border + 极轻阴影（opacity 0.04-0.08）。

hover 时阴影加深暗示交互，过渡 0.15s ease 保证流畅。

侧边栏用 border-right 与内容区分，而非阴影。

卡片之间用 gap（间距）而非阴影区分，更干净。

字体系统

使用系统原生字体栈，不加载 Web Font，保证加载速度。

中文优先：PingFang SC → Hiragino Sans GB → Microsoft YaHei

数字/代码：SF Mono / Fira Code 等宽字体，增强数据可读性。

字重层级：600（标题）→ 500（强调）→ 400（正文）

交互反馈

所有可交互元素 hover 有明确反馈（背景色变化 / 边框色变化）。

输入框聚焦：橙色边框 + 2px 外发光（accent-bg 透明度）。

按钮点击：背景色加深 5-10%，过渡 0.15s。

表格行 hover：浅灰背景，不影响边框。

与 Element UI 兼容

所有设计基于 Element UI 2.x 可覆盖的 CSS 属性。

通过 CSS Variables 统一管理，便于主题切换。

不需要修改 Element UI 源码，仅通过全局样式覆盖实现。

暗色模式可通过切换 CSS Variables 一键实现。

维度 之前方案（A/B/C） 本方案（新锐科技风）
视觉感受 模板化、AI 生成感 手工打磨、商业产品质感
色彩使用 橙色大面积使用，视觉疲劳 橙色克制点缀（<5%），灰阶为主
阴影处理 重阴影 / 发光效果 极轻阴影 + border，干净通透
参考对象 通用后台模板 Linear / Vercel / 飞书 / Stripe
字体处理 默认字体 系统字体栈 + 等宽数字
暗色模式 未考虑 CSS Variables 一键切换
Element UI 兼容 需大量覆盖 最小化覆盖，利用默认样式
